Section 2 - Derivatives of Products and Quotients

Introduction

  1. The manager of a miniature golf course is planning to raise the ticket price per game. At the current price of \$6.50, an average of 81 rounds is played each day. The manager’s research suggests that for every \$0.50 increase in price, an average of four fewer games will be played each day. Based on this information, find the function that represents revenue from rounds of mini golf, where n represents the number of \$0.50 increases in price.

    How to get the Solution: $R(n) =$ (price)(number sold)

    Answer to Problem: $R(n) = (6.50 + .50n)(81 - 4n)$

    1. What must you do with this revenue function in order to find the rate of change?

      Answer to Problem: Multiply it out and use the power rule to find the derivative.

    2. Find the rate of change for this revenue function when the manager increases the price of a round of mini golf by \$1.50.

      How to get the Solution:  $R(n) = 526.50 + 14.5n - 2{n^2}$

      $R'(n) = 14.5 - 4n$

      If the price is increased by \$1.50, then there have been 3 fifty cent increases, so $n=3$.

      $R'(3) = 2.5$

      Answer to Problem: When the manager increases the price per ticket by \$$1.50$, the number of rounds played each day decreases but the actual revenue increases by \$$2.50$ per day. This provides the owner with an increase in revenue even though there is a decrease in the number of rounds played each day.

  2. Find the rate of change for the function $y = ({x^2} + 1)({x^2} - 2x + 1)$

    Answer to Problem: This problem can be worked the same way but it is much harder to multiply out. We need an easier way to find the derivative when we have polynomial terms multiplied together.

  3. The cost of manufacturing x MP3 players per day is represented by the function $$C(x) = 0.01{x^2} + 42x + 300\quad 0 \le x \le 300.$$

    1. Determine the average cost function.

      Answer to Problem: $\bar C(x) = \frac{{0.01{x^2} + 42x + 300}}{{x}}$

    2. Determine the marginal average cost function. What did you have to do to the average cost function in order to find the marginal average cost function?

      Answer to Problem: The marginal average cost is the derivative of the average cost.

      How to get the Solution: Must rewrite the function to use the power rule.

      $\bar C(x) = 0.01x + 42 + \frac{{300}}{{x}}$

      $\bar C(x) = 0.01x + 42 + 300{x^{ - 1}}$

      $\bar C'(x) = 0.01 - 300{x^{ - 2}}$

      Answer to Problem: $\bar C'(x) = 0.01 - \frac{{300}}{{{x^2}}}$

  4. Suppose the function $V(t) = \frac{{50,000 + 6t}}{{1 + 0.4t}}$ represents the value, in dollars, of a new car t years after it is purchased. Determine the rate of change in the value of the car.

    Answer to Problem: Cannot rewrite to use the power rule as we did for #6. We need another new rule.

Derivatives of Products and Quotients

Let's first practice rewriting a Function as a Product or Quotient

  1. Rewrite as a product: $f\left( x \right) = 5{e^x}\; + \;\;10{x^2}\;{e^x}\; + \;\;25{x^4}\;{e^x}$

    Answer to Problem: $f(x) = 5{e^x}(1 + 2{x^2} + 5{x^4})$

  2. Rewrite as one quotient: $f\left( x \right) = 3{x^{ - 4}}\ln x$

Answer to Problem: $f(x) = \frac{{3\ln x}}{{{x^4}}}$

The Product and Quotient Rule

The Product Rule: If $y=f(x)\cdot g(x)$,

then $y' = f'(x)\cdot g(x)\; + \;\;f(x)\cdot g'(x)$

The Quotient Rule: If $y = \;\frac{f(x)}{g(x)},$

then $y' = \;\frac{{f'(x)\;g(x)\; - \;f(x)\;g'(x)\;}}{{[{g(x)}}]^2}$

Two Methods for Finding the Derivative:

Find the derivative two different ways.

  1. Simplify first and use the power rule.
  2. Use the product or quotient rule.

  1. $m\left( x \right) = 2{x^3}\;\left( {{x^5} - 2} \right)$

    1. How to get the Solution: Simplifying and Using Power Rule

      $m(x) = 2{x^8} - 4{x^3}$

      Answer to Problem: ${m'}(x) = 16{x^7} - 12{x^2}$

    2. How to get the Solution: Using the Product Rule

      Do this as the side work, set up $f$, $f'$, $g$, and $g'$

      $f = 2{x^3}$

      $f' = 6{x^2}$

      $g = {x^5} - 2$

      $g' = 5{x^4}$

      Now go back to the formula for product rule and plug in your side work

      $m'(x) = 6{x^2}({x^5} - 2) + 2{x^3}(5{x^4})$

      $m'(x) = 6{x^7} - 12{x^2} + 10{x^7}$

      Answer to Problem: $m'(x) = 16{x^7} - 12{x^2}$

  2. $r\left( x \right) = \;\frac{{{x^5}+4}}{{{x^2}}}$

    1. How to get the Solution: Simplifying and Using Power Rule

      $r(x) = \frac{{{x^5}}}{{{x^2}}} + \frac{{4}}{{{x^2}}}$

      $r(x) = {x^3} + 4{x^{ - 2}}$

      ${r'}(x) = 3{x^2} - 8{x^{ - 3}}$

      Answer to Problem: ${r'}(x) = 3{x^2} - \frac{{8}}{{{x^3}}}$

    2. How to get the Solution: Using Quotient Rule

      Do this as the side work, set up $f$, $f'$, $g$, and $g'$

      $f = {x^5} + 4$

      $f' = 5{x^4}$

      $g = {x^2}$

      $g' = 2x$

      Now go back and use the quotient rule formula

      $r'(x) = \frac{{5{x^4}({x^2}) - 2x({x^5} + 4)}}{{({x^2})^2}}$

      $r'(x) = \frac{{5{x^6} - 2{x^6} - 8x}}{{{x^4}}}$

      $r'(x) = \frac{{3{x^6} - 8x}}{{{x^4}}}$

      $r'(x) = \frac{{x(3{x^5} - 8)}}{{{x^4}}}$

      $r'(x) = \frac{{3{x^5} - 8}}{{{x^3}}}$

      Answer to Problem: $r'(x) = 3{x^2} - \frac{{8}}{{{x^3}}}$

Find $f'(x)$ using the Product Rule.

  1. $n(x)=7x^2\left(2x^3+5\right)$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f = 7{x^2}$

    $f' = 14x$

    $g = 2{x^3} + 5$

    $g' = 6{x^2}$

    Now back to the formula for product rule to get the derivative

    $n'(x) = 14x(2{x^3} + 5) + 7{x^2}(6{x^2})$

    $n'(x) = 28{x^4} + 70x + 42{x^4}$

    Answer to Problem: $n'(x) = 70{x^4} + 70x$

  2. $h\left( x \right) = 4{x^3}\;{e^x}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f = 4{x^3}$

    $f' =12{x^2}$

    $g = {e^x}$

    $g' = {e^x}$

    Now go back to your formula

    $h'(x) = 12{x^2}({e^x}) + 4{x^3}({e^x})$

    $h'(x) = {e^x}(12{x^2} + 4{x^3})$

    Answer to Problem: $h'(x) = 4{x^2}{e^x}(3 + x)$

  3. $s\left( x \right) = 2{x^5}\ln x$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f = 2{x^5}$

    $f' =10{x^4}$

    $g = \ln x$

    $g' = \frac{{1}}{{x}}$

    Now the formula for product rule

    $s'(x) = 10{x^4}\ln x + 2{x^5}\left( {\frac{{1}}{{x}}} \right)$

    $s'(x) = 10{x^4}\ln x + 2{x^4}$

    Answer to Problem: $s'(x) = 2{x^4}(5\ln x + 1)$

  4. $v\left( x \right) = \left( {8x + 1} \right)\left( {3{x^2}\; - 7} \right)$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f = 8x + 1$

    $f' =8$

    $g = 3{x^2} - 7$

    $g' = 6x$

    $v'(x) = 8(3{x^2} - 7) + 6x(8x + 1)$

    $v'(x) = 24{x^2} - 56 + 48{x^2} + 6x$

    Answer to Problem: $v'(x) = 72{x^2} + 6x - 56$

Examples Using the Quotient Rule

  1. $b\left( x \right) = \;\frac{{4x}}{{3x + 8}}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f =4x$

    $f' =4$

    $g =3x+8$

    $g' = 3$

    $b'(x) = \frac{{4(3x + 8) - 3(4x)}}{{{{\left( {3x + 8} \right)}^2}}}$

    $b'(x) = \frac{{12x + 32 - 12x}}{{{{\left( {3x + 8} \right)}^2}}}$

    Answer to Problem: $b'(x) = \frac{{32}}{{{{\left( {3x + 8} \right)}^2}}}$

  2. $c\left( x \right) = \;\frac{{{x^2}\; - 9}}{{{x^2}\; + 1}}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f ={x^2} - 9$

    $f' =2x$

    $g ={x^2} + 1$

    $g' = 2x$

    $c'(x) = \frac{{2x({x^2} + 1) - 2x({x^2} - 9)}}{{{{\left( {{x^2} + 1} \right)}^2}}}$

    $c'(x) = \frac{{2{x^3} + 2x - 2{x^3} + 18x}}{{{{\left( {{x^2} + 1} \right)}^2}}}$

    Answer to Problem: $c'(x) = \frac{{20x}}{{{{\left( {{x^2} + 1} \right)}^2}}}$

  3. $h\left( x \right) = \;\frac{{1 + {e^x}}}{{1 - {e^x}}}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f =1 + {e^x}$

    $f' = {e^x}$

    $g = 1 - {e^x}$

    $g' = - {e^x}$

    $h'(x) = \frac{{{e^x}(1 - {e^x}) - \left( { - {e^x}} \right)(1 + {e^x})}}{{{{\left( {1 - {e^x}} \right)}^2}}}$

    $h'(x) = \frac{{{e^x}(1 - {e^x}) + {e^x}(1 + {e^x})}}{{{{\left( {1 - {e^x}} \right)}^2}}}$

    $h'(x) = \frac{{{e^x} - {e^{{2x}}} + {e^x} + {e^{{2x}}}}}{{{{\left( {1 - {e^x}} \right)}^2}}}$

    Answer to Problem: $h'(x) = \frac{{2{e^x}}}{{{{\left( {1 - {e^x}} \right)}^2}}}$

  4. $j\left( x \right) = \;\frac{{3x}}{{4 + \ln x}}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f =3x$

    $f' = 3$

    $g =4 + \ln x$

    $g' = \frac{{1}}{{x}}$

    $j'(x) = \frac{{3(4 + \ln x) - \frac{{1}}{{x}}(3x)}}{{{{\left( {4 + \ln x} \right)}^2}}}$

    $j'(x) = \frac{{12 + 3\ln x - 3}}{{{{\left( {4 + \ln x} \right)}^2}}}$

    Answer to Problem: $j'(x) = \frac{{9 + 3\ln x}}{{{{\left( {4 + \ln x} \right)}^2}}}$

  5. Find $\frac{{dy}}{{dw}}$ for $y = \;\frac{{2{w^4}\; - \;{w^3}}}{{6w - 1}}$

    How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

    $f =2{w^4} - {w^3}$

    $f' = 8{w^3} - 3{w^2}$

    $g = 6w - 1$

    $g' = 6$

    $\frac{{dy}}{{dw}} = \frac{{(8{w^3} - 3{w^2})(6w - 1) - 6(2{w^4} - {w^3})}}{{{{\left( {6w - 1} \right)}^2}}}$

    $\frac{{dy}}{{dw}} = \frac{{48{w^4} - 8{w^3} - 18{w^3} + 3{w^2} - 12{w^4} + 6{w^3}}}{{{{\left( {6w - 1} \right)}^2}}}$

    Answer to Problem: $\frac{{dy}}{{dw}} = \frac{{36{w^4} - 20{w^3} + 3{w^2}}}{{{{\left( {6w - 1} \right)}^2}}}$

  6. Explain how $f'(x)$ can be found without using the quotient rule: $f\left( x \right) = \;\frac{{3}}{{{x^3}}}$

    How to get the Solution: $f(x) = 3{x^{ - 3}}$

    $f'(x) = - 9{x^{ - 4}}$

    Answer to Problem: $f'(x) = \frac{{ - 9}}{{{x^4}}}$

    Tangent Lines

  7. $r\left( x \right) = \left( {5 - 4x} \right)\left( {1 + 3x} \right)$

    1. Find $r'\left( x \right)$

      How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

      $f = 5 - 4x$

      $f' = - 4$

      $g = 1 + 3x$

      $g' = 3$

      $r'(x) = - 4(1 + 3x) + 3(5 - 4x)$

      $r'(x) = - 4 - 12x + 15 - 12x$

      Answer to Problem: $r'(x) = - 24x + 11$

    2. Find the equation of the line tangent to the graph of $r$ at $x\; = \;2$.

      How to get the Solution: Point $\quad r(2) = (5 - 4\cdot2)(1 + 3\cdot2) = ( - 3)(7) = -21$

      Answer to Problem: $(2, - 21)$

      How to get the Solution: Slope $\quad {m_{{tan}}}= {r'}(2) = - 24(2) + 11=-48+11=-37$

      Answer to Problem: ${m_{{tan}}}=-37$

      How to get the Solution: $y + 21 = - 37(x - 2)$

      $y + 21 = - 37x + 74$

      Answer to Problem: $y = - 37x + 53$

    3. Find the values of $x$ where $r’(x) = 0$

      How to get the Solution: $ - 24x + 11 = 0$

      $ - 24x = - 11$

      Answer to Problem: $x = \frac{{11}}{{24}}$

  8. $h\left( x \right) = \;\frac{{3x - 7}}{{2x - 1}}$

    1. Find $h'\left( x \right)$

      How to get the Solution: Do this as the side work, set up $f$, $f'$, $g$, and $g'$

      $f =3x - 7$

      $f' = 3$

      $g = 2x - 1$

      $g' = 2$

      $h'(x) = \frac{{3(2x - 1) - 2(3x - 7)}}{{{{\left( {2x - 1} \right)}^2}}}$

      $h'(x) = \frac{{6x - 3 - 6x + 14}}{{{{\left( {2x - 1} \right)}^2}}}$

      Answer to Problem: $h'(x) = \frac{{11}}{{{{\left( {2x - 1} \right)}^2}}}$

    2. Find the equation of the line tangent to the graph of $h$ at $x\; = \;2$.

      How to get the Solution: Point $\quad h(2) = \frac{{3\cdot2 - 7}}{{2\cdot2 - 1}} = \frac{{ - 1}}{{3}}$

      Answer to Problem: $(2, - \frac{{1}}{{3}})$

      How to get the Solution: Slope $\quad {m_{{tan}}} = f'(2) = \frac{{11}}{{{{\left( {2\cdot2 - 1} \right)}^2}}} = \frac{{11}}{{{3^2}}} = \frac{{11}}{{9}}$

      Answer to Problem: ${m_{{tan}}} = \frac{{11}}{{9}}$

      How to get the Solution: $y + \frac{{1}}{{3}} = \frac{{11}}{{9}}(x - 2)$

      $y + \frac{{1}}{{3}} = \frac{{11}}{{9}}x - \frac{{22}}{{9}}$

      Answer to Problem: $y = \frac{{11}}{{9}}x - \frac{{25}}{{9}}$

    3. Find the values of x where h’(x) = 0

      How to get the Solution: $\frac{{11}}{{{{(2x - 1)}^2}}} = 0$

      $\frac{{11}}{{{{(2x - 1)}^2}}} = \frac{{0}}{{1}}$

      Cross Multiply

      Answer to Problem: $0 \ne 11$ There is no value of x where $f'(x) =0$

Derivatives with Radicals

    1. Find y’ for $y = \;\frac{{6\sqrt[3]{{x}}}}{{2{x^2}\; - 5x + 1}}$

      How to get the Solution: $f(x)=\frac{{6{x^{1/3}}}}{{2{x^2} - 5x + 1}}$

      $f =6{x^{1/3}}$

      $f' = \frac{{1}}{{3}}\cdot 6{x^{ - 2/3}}$

      $f' = 2{x^{ - 2/3}}$

      $g = 2{x^2} - 5x + 1$


      $g' = 4x - 5$

      $y' = \frac{{2{x^{ - 2/3}}(2{x^2} - 5x + 1) - (4x - 5)(6{x^{1/3}})}}{{{{\left( {2{x^2} - 5x + 1} \right)}^2}}}$

      $y' = \frac{{4{x^{4/3}} - 10{x^{1/3}} + 2{x^{ - 2/3}} - 24{x^{4/3}} + 30{x^{1/3}}}}{{{{\left( {2{x^2} - 5x + 1} \right)}^2}}}$

      $y' = \frac{{ - 20{x^{4/3}} + 20{x^{1/3}} + 2{x^{ - 2/3}}}}{{{{\left( {2{x^2} - 5x + 1} \right)}^2}}}$

      Multiply every term by ${{{x}}^{2/3}}$

      Answer to Problem: $y' = \frac{{ - 20{x^2} + 20x + 2}}{{\sqrt[3]{{{x^2}}}{{(2{x^2} - 5x + 1)}^2}}}$

    2. Find $\frac{{dy}}{{dx}}$ for $y = \;\frac{{\;2{x^2}\; - 2x + 3\;}}{{\sqrt[4]{{x}}}}$

      How to get the Solution: $f =2{x^2} - 2x + 3$

      $f' = 4x - 2$

      $g = {x^{1/4}}$

      $g' = \frac{{1}}{{4}}{x^{ - 3/4}}$

      $\frac{{dy}}{{dx}} = \frac{{(4x - 2)({x^{1/4}}) - \frac{{1}}{{4}}{x^{ - 3/4}}(2{x^2} - 2x + 3)}}{{{{\left( {{x^{1/4}}} \right)}^2}}}$

      $\frac{{dy}}{{dx}} = \frac{{4{x^{5/4}} - 2{x^{1/4}} - \frac{{1}}{{2}}{x^{5/4}} + \frac{{1}}{{2}}{x^{1/4}} - \frac{{3}}{{4}}{x^{ - 3/4}}}}{{{x^{1/2}}}}$

      $\frac{{dy}}{{dx}} = \frac{{\left( {\frac{{7}}{{2}}{x^{5/4}} - \frac{{3}}{{2}}{x^{1/4}} - \frac{{3}}{{4}}{x^{ - 3/4}}} \right)\cdot 4}}{{({x^{1/2}})\cdot 4}}$

      $\frac{{dy}}{{dx}} = \frac{{14{x^{5/4}} - 6{x^{1/4}} - 3{x^{ - 3/4}}}}{{(4{x^{1/2}})}}$

      $\frac{{dy}}{{dx}}=\frac{14{{{x}}^{5/4}}-6{{{x}}^{1/4}}-\frac{{3}}{{{{x}}^{{}^{{3}}/{}_{{4}}}}}}{4{{{x}}^{1/2}}}$

      Multiply every term by ${{{x}}^{3/4}}$

      $\frac{{dy}}{{dx}}=\frac{14{{{x}}^{8/4}}-6{{{x}}^{4/4}}-3}{(4{{{x}}^{1/2}}){{{x}}^{3/4}}}$

      Answer to Problem: $\frac{{dy}}{{dx}}=\frac{14{{{x}}^{{2}}}-6x-3}{4{{{x}}^{5/4}}}$

Applications

  1. A cable company has installed a new television system in a city. The total number N (in thousands) of subscribers t months after the installation of the system is given by $N\left( t \right) = \;\frac{{178t}}{{t + 5}}$

    1. Find $N'(t)$

      How to get the Solution: $f =178t$

      $f' = 178$

      $g = t + 5$

      $g' = 1$

      $N'(t) = \frac{{178(t + 5) - 1(178t)}}{{{{\left( {t + 5} \right)}^2}}}$

      $N'(t) = \frac{{178t + 890 - 178t}}{{{{\left( {t + 5} \right)}^2}}}$

      Answer to Problem: $N'(t) = \frac{{890}}{{{{\left( {t + 5} \right)}^2}}}$

    2. Find $N\left( {{12}} \right)$ and $N'\left( {{12}} \right)$. Write a brief interpretation of these results.

      How to get the Solution: $N(12) = \frac{{178(12)}}{{12 + 5}} = \frac{{2136}}{{17}} = 125.647$

      $N'(12) = \frac{{890}}{{{{\left( {12 + 5} \right)}^2}}} = \frac{{890}}{{{{{17}}^2}}} = \frac{{890}}{{289}} = 3.0796$

      Answer to Problem: At 12 months the cable company has 125,647 subscribers and that number is increasing at a rate of 3080 subscribers per month.

    3. Use the results above to estimate the total number of subscribers after 13 months.

      How to get the Solution: 125,647 + 3080 = 128,727

      Answer to Problem: There will be approximately 128,727 subscribers after 13 months.

  2. According to economic theory, the supply x of a quantity in a free market increases as the price p increases. Suppose the number x of baseball gloves a retail chain is willing to sell per week at a price of \$p is given by $$x = \;\frac{{100p}}{{0.1p + 1}} \quad\ 30.00 \le p \le 190.00$$

    1. Find $\frac{{dx}}{{dp}}$

      How to get the Solution: $f =100p$

      $f' = 100$

      $g =0.1p + 1$

      $g' = 0.1$

      $\frac{{dx}}{{dp}} = \frac{{100(0.1p + 1) - 0.1(100p)}}{{{{\left( {0.1p + 1} \right)}^2}}}$

      $\frac{{dx}}{{dp}} = \frac{{10p + 100 - 10p}}{{{{\left( {0.1p + 1} \right)}^2}}}$

      Answer to Problem: $\frac{{dx}}{{dp}} = \frac{{100}}{{{{\left( {0.1p + 1} \right)}^2}}}$

    2. Find the supply and the instantaneous rate of change (IRC) of supply with respect to price when the price is \$40. Write a brief verbal interpretation of these results.

      How to get the Solution: Supply when $p=\$40\quad\quad\quad x = \frac{{100(40)}}{{0.1(40) + 1}} = \frac{{4000}}{{5}} = 800\;gloves$

      IRC when $p=\$40\quad\quad\quad \frac{{dx}}{{dp}}=\frac{{100}}{{{{\left({0.1\cdot40+1}\right)}^2}}} = \frac{{100}}{{25}} = 4\;gloves$

      Answer to Problem: When the price of the baseball gloves is \$40, the retail chain can sell 800 gloves per week, and the number of gloves sold is increasing at a rate of 4 gloves per week.

    3. Use the results above to estimate the supply if the price is increased to \$41.

      How to get the Solution: 800+4=804

      Answer to Problem: If the price increased to \$41, 804 gloves would be sold each week.
