Objectives for Unit 2

After watching the videos and completing the homework for this chapter, you should be able to do the following:

Objectives for Section 1: Techniques for Differentiation

  • Find the derivative using the power rule
  • Find the equation of the tangent line given the point of tangency
  • Find the points on a graph where the tangent line will be horizontal

Objectives for Section 2: Derivatives for Products and Quotients

  • Find the derivative using the product rule
  • Find the derivative using the quotient rule

Objectives for Section 3: The Chain Rule

  • Review composition of functions
  • Write functions as the composition of two (or more) functions
  • Use the chain rule to find the derivative of a function
  • Find the equation of a tangent line after using the chain rule

Objectives for Section 4: Derivatives of Exponential Functions

  • Find the derivative of exponential functions
  • Solve application problem involving the derivative of exponential functions

Objectives for Section 5: Derivatives of Logarithmic Functions

  • Find the derivative of logarithmic functions
  • Solve application problem involving the derivative of logarithmic functions
