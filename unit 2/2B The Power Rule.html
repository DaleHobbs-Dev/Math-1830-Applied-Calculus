Basic Differentiation Properties

These three notations are commonly used to represent the derivative of a function:

If $y\; = \;\;f\left( x \right),\;$ you can use any of these to represent the derivative $y' = f'\left( x \right) = \frac{dy}{dx}$

THE POWER RULE:

If $f\left( x \right) = {x^n}$ then $f'\left( x \right) = n{x^{n - 1}}$

Using the Power Rule

Find the indicated derivative using the power rule for finding derivatives:

📝Notation Note: Using $\frac{d}{dx}\left[\ldots\right]$

Whenever you see the operator $\frac{d}{dx}\left[\ldots\right]$, this means “take the derivative of $\ldots$.” It's an indication used inside these notes to signal that we are about to perform differentiation on the expression inside the brackets and isn't something needed to be written out explicitly.

  1. Problem

    $g\left( x \right) = {x^4}$

    Solution

    The power rule states that if $f(x) = x^n$, then $f'(x) = nx^{n-1}$. Applying that here will have us bringing the power of 4 down as a coefficient and reducing the exponent by 1. Therefore, $g'(x) = 4x^{4-1}$ reducing to $g'(x) = 4x^3$.

    Answer

    $g'\left( x \right) = 4{x^3}$

  2. Problem

    $y = 2{x^3}$

    Answer

    $y' = 6{x^{ 2}}$

  3. Problem

    $\frac{d}{dx}\left( 5 \right)$

    Solution

    If you don't see an $x$, you can always add in an $x^0$ to the problem, which is equivalent to 1. Then you can easily see the power rule in action. This becomes $\frac{d}{dx}\left( 5 \right) = \frac{d}{dx}\left( {5x^0} \right) = 5\left( 0 \right){x^{ - 1}} =$

    Answer

    $0$. One thing you may want to just remember is this: the derivative of a constant is ALWAYS 0.

  4. Problem

    $y = \;\frac{1}{x^7} = {x^{ - 7}}$

    Answer

    $y' = - 7{x^{ - 8}} = \frac{ - 7}{x^8}$

  5. Problem

    $y = \;\frac{x^4}{16}$

    Answer

    $\frac{dy}{dx} = \frac{4x^3}{16} = \frac{x^3}{4}$

  6. Problem

    $y\; = 8 + 3t - 5{t^3}$

    Answer

    $\frac{dy}{dt} = 0 + 3 - 15{t^2} = 3 - 15{t^2}$

  7. Problem

    $g\left( x \right) = 6{x^{ - 5}} - \;\;5{x^{ - 4}}$

    Solution

    $g'\left( x \right) = - 30{x^{ - 6}} + 20{x^{ - 5}} =$

    Answer

    $ \frac{ - 30}{x^6} + \frac{20}{x^5}$

  8. Problem

    $\frac{d}{dx}\left( {\frac{4x^3}{10}\; - \;\;\frac{2}{3x^4}} \right)$

    Solution

    $\frac{d}{dx}\left( {\frac{4}{10}{x^3} - \frac{2}{3}{x^{ - 4}}} \right)$

    $\frac{d}{dx} = \frac{12}{10}{x^2} + \frac{8}{3}{x^{ - 5}} = $

    Answer

    $\frac{6x^2}{5} + \frac{8}{3x^5}$

  9. Problem

    $H'\left( w \right)$ if $H\left( w \right) = \;\frac{5}{w^6}\; - \;\;7\sqrt w$

    Solution

    $H(w)= 5{w^{ - 6}} - 7{w^{1/2}}$

    $H'(w) = - 30{w^{ - 7}} - \frac{7}{2}{w^{ - 1/2}} =$

    Answer

    $ \frac{ - 30}{w^7} - \frac{7}{2\sqrt w }$

  10. Problem

    $\frac{d}{du}\left( {7u^{2/3}\;\; + \;\;\;4u^{ - 3/5}} \right)$

    Answer

    $\frac{d}{du} = \frac{14}{3}{u^{ - 1/3}} - \frac{12}{5}{u^{ - 8/5}}$

  11. Problem 🖥️Technology Enhanced

    Find and approximate the value(s) of $\;x$ where the graph of $\;f\left( x \right) = 2{x^2}\; - 5x\;$ has a horizontal tangent line. You can use a graphing calculator or Desmos to verify your answer.

    Solution

    We see the derivative is $f'(x) = 4x - 5$ by using the power rule. Now, the graph of f has a horizontal tangent where $f'(x) = 0$ (think about the slope of a horizontal line: it would be 0 and since the derivative is the "slope of the tangent line", this equation should make sense). So simplifying this and solving for $x$ will give you the places on the graph of $f$ that have a horizontal tangent line. We get $4x - 5 = 0$ and then $4x = 5$.

    Answer

    $x = \frac{5}{4}$

  12. Problem

    A company’s total sales (in millions of dollars) t months from now are given by $S\left( t \right) = 0.032{t^4}\;\; + 0.5{t^3}\; + 2.8{t^2}\; + 9t - 4$

    1. Find $S'\left( t \right)$

      Answer

      $S'\left( t \right) = 0.128{t^3} + 1.5{t^2} + 5.6t + 9$

    2. Find $S\left( 4 \right)$ and $S'\left( 4 \right)$ Write a brief verbal interpretation of these results.

      Solution

      We plug $x=4$ into the original equation to get $S(4) = 0.032{(4)^4} + 0.5{(4)^3} + 2.8{(4)^2} + 9(4) - 4 = 116.99$. Then we plug $x=4$ into the derivative to get the rate of change in the company's sales at 4 months in. This will be $S'(4) = 0.128{(4)^3} + 1.5{(4)^2} + 5.6(4) + 9 = 63.59$.

      Answer

      Total sales after 4 months are \$116.99 million. The sales are increasing at a rate of $63.59 million per month.

    3. Find $S\left( 8 \right)$ and $S'\left( 8 \right)$ Write a brief verbal interpretation of these results.

      Solution

      We plug $x=8$ into the original equation to get $S(8) = 0.032{(8)^4} + 0.5{(8)^3} + 2.8{(8)^2} + 9(8) - 4 = 634.27$. Then we plug $x=8$ into the derivative to get the rate of change in the company's sales at 8 months in. This will be $S'(8) = 0.128{(8)^3} + 1.5{(8)^2} + 5.6(8) + 9 = 215.34$.

      Answer

      Total sales after 8 months are \$634.27 million. The sales are increasing at a rate of $215.34 million per month.
