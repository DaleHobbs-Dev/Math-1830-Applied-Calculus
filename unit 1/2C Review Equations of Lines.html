Review 2: Writing Equations of Lines

Reviewing Slope and Slope-Intercept Form

Some problems can be represented by linear equations which can then be used to find solutions or make predictions. In this activity you will use slopes and ordered pairs to write expressions that model these problems.

Problem

You need to find a formula for the number of cars produced by a new plant that was opened 25 days ago. You are told that three days ago the plant had 450 cars on hand, and that yesterday it had 480 cars on hand. You are also told that some of these cars came from previous inventory. Assume that the plant produces cars at this same rate and has produced them at this same rate since it opened. Define "x" to be the time from today and "y" to be the number of cars on hand. Therefore, an ordered pair (x, y) will represent (time from today, number of cars on hand).

  1. Write an ordered pair using the information about the cars on hand three days ago.

    Answer

    $\left(-3, 450\right)$

  2. Write a second ordered pair using the information about the cars on hand yesterday.

    Answer

    $\left(-1, 480\right)$

  3. You need to know the rate at which the plant is producing cars. Another name for this rate of change is "slope." Use the two ordered pairs to find the rate of change.

    Solution

    $m = \frac{{y_2} - {y_1}}{{x_2} - {x_1}} = \frac{480 - 450}{-1 - (-3)} = \frac{30}{2} = 15$

    Answer

    The plant is producing 15 cars per day.

  4. Use the slope and one of the ordered pairs (doesn't matter which one!) to write a linear equation describing this problem. Use point-slope form: $y - y_1 = m(x - x_1)$.

    Answer

    Using point $\left(-3, 450\right)$: $y - 450 = 15(x - (-3))$

    Using point $\left(-1, 480\right)$: $y - 480 = 15(x - (-1))$

  5. Write the equation in slope-intercept form: $y = mx + b$.

    Answer

    $y = 15x + 495$

  6. Now write the equation in standard form: $ax + by = c$.

    Answer

    $y = 15x + 495$ then move the $15x$ to the other side to get $-15x + y = 495$. Lastly, we often want the value in front of the $x$ to be positive so just multiply by $-1$ throughout the problem to arrive at the final answer of $15x - y = -495$

  7. Use the equation to find the number of cars the plant had on hand when it opened.

    Solution

    Because the plant opened 25 days ago, $x = -25$. So substitute this $x$-value into the equation we got in part (e) to get $y = 15(-25) + 495 = 120$ cars

    Answer

    On the day the plant opened, there were 120 cars on hand.

  8. Use the equation to find the number of cars the plant will have on hand in five days.

    Assume in 5 days means 5 days from today.

    Solution

    $y = 15(5) + 495 = 570$ cars

    Answer

    Five days from today, the plant will have 570 cars on hand.

  9. Use the equation to find when the plant will have 675 cars on hand.

    Solution

    $y = 675$. Set your equation from part (e) equal to this value to get $675 = 15x + 495$ where you can now solve for $x$ and see that $x = 12$.

    Answer

    Twelve days from today, the plant will have 675 cars.

  10. Graph the equation on the interval [-3,13].

    $y = 15x + 495$

    • x axis: time from today, in days
    • y axis: number of cars on hand

    Answer

Problem

Ally Bank is offering its customers a 2-year Certificate of Deposit (CD) paying 1.29% (APR) with no minimum deposit. Define x to be the amount deposited and y to be the APR.

  1. Write ordered pairs that would represent depositing $100, $1000, and $5000 in the CD.

    Answer

    $(100, 1.29)$, $(1000, 1.29)$, $(5000, 1.29)$

  2. What is the rate of change of the APR?

    Solution

    You can use slope formula to find the rate of change between two points. This gives you $m = \frac{{y_2} - {y_1}}{{x_2} - {x_1}} = \frac{1.29 - 1.29}{1000 - 100} = \frac{0}{900}$

    Answer

    $m = 0$

  3. Find the linear equation that represents this problem.

    Answer

    $y = 1.29$

  4. Graph the equation.

    Answer

Problem

For each of the sets of points below, find: First, the slope of the line. Second, the slope intercept form of the line. Third, the standard form of the line. And Fourth, the y intercept and the x intercept of the line.

  1. (3, 5) and (-1, 7)

    1. Slope:

      Solution

      $m = \frac{7 - 5}{-1 - 3} = \frac{2}{-4} = -\frac{1}{2}$

      Answer

      $-\frac{1}{2}$

    2. Slope-intercept form:

      Solution

      $y - 5 = -\frac{1}{2}(x - 3) \Rightarrow y - 5 = -\frac{1}{2}x + \frac{3}{2}$

      Answer

      $y = -\frac{1}{2}x + \frac{13}{2}$

    3. Standard form:

      Solution

      $y = -\frac{1}{2}x + \frac{13}{2} \Rightarrow 2y = -x + 13$

      Answer

      $x + 2y = 13$

    4. Intercepts:

      Answer

      y-intercept: $(0, \frac{13}{2})$ and x-intercept: $(13, 0)$

  2. (2, 7) and (2, -3)

    1. Slope:

      Solution

      $m = \frac{7 - (-3)}{2 - 2} = \frac{10}{0}$

      Answer

      undefined slope

    2. Slope-intercept form:

      Answer

      $x = 2$

    3. Standard form:

      Answer

      $x = 2$

    4. Intercepts:

      Answer

      y-intercept: none and x-intercept: $(2, 0)$

  3. (1, 3) and (0, 3)

    1. Slope:

      Solution

      $m = \frac{3 - 3}{1 - 0} = \frac{0}{1}$

      Answer

      $0$

    2. Slope-intercept form:

      Answer

      $y = 3$

    3. Standard form:

      Answer

      $y = 3$

    4. Intercepts:

      Answer

      y-intercept: $(0, 3)$ and x-intercept: none

  4. (-4, -8) and (-3, -4)

    1. Slope:

      Solution

      $m = \frac{-8 - (-4)}{-4 - (-3)} = \frac{-4}{-1} = 4$

      Answer

      $4$

    2. Slope-intercept form:

      Solution

      Take the slope from part (i) and the point-slope formula and plug in. This gives you $y + 8 = 4(x + 4)$. Go ahead and distribute 4 to get $y + 8 = 4x + 16$. Now finish solving for $y$.

      Answer

      $y = 4x + 8$

    3. Standard form:

      Solution

      $y - 4x = 8$ then $-y + 4x = -8$

      Answer

      $4x - y = -8$

    4. Intercepts:

      Answer

      y-intercept: $(0, 8)$ and x-intercept: $(-2, 0)$
